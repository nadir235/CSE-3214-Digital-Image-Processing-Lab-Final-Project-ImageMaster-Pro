# ImageMaster Pro - Digital Image Processing Lab Suite

**A complete Digital Image Processing (DIP) project covering all 6 lab tasks in one unified Google Colab notebook.**

---

## 📋 Project Overview

**ImageMaster Pro** is a comprehensive Digital Image Processing project developed for academic lab work. It includes all experiments from basic image loading to advanced enhancement techniques in a single, easy-to-use interface.

### Lab Tasks Covered:
- **Lab 1**: Image to Array & Basic Information
- **Lab 2**: Grayscale Conversion
- **Lab 3**: Negative Transformation
- **Lab 4**: Gamma Transformation (γ = 0.5 & 2.0)
- **Lab 5**: Histogram Analysis & Equalization
- **Lab 6**: Mini Project - Combined Enhancement Techniques

---

## ✨ Features

- **One-Click Execution**: Single button to run all labs
- **Beautiful Dashboard**: Side-by-side comparison of all results
- **Automatic Saving**: All processed images are saved
- **ZIP Download**: Download all results with one click
- **Interactive Upload**: Easy image upload widget
- **Professional Visualization**: Using Matplotlib and OpenCV
- **Well-documented Code**: Easy to understand and modify

---

## 🚀 How to Use

### Method 1: Google Colab (Recommended)

1. Open [Google Colab](https://colab.research.google.com/)
2. Create a new notebook
3. Copy and paste the complete code from `ImageMaster_Pro.ipynb`
4. Run the first cell to install dependencies
5. Upload your image when prompted
6. Click the **"🚀 Run All Labs"** button

### Method 2: Local Environment


git clone https://github.com/yourusername/imagemaster-pro.git
cd imagemaster-pro
pip install opencv-python matplotlib numpy ipywidgets
jupyter notebook
